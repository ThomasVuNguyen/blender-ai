# 001 — Sandwich study

Created October 24, 2026 as the first test of the local **MCP for Blender** connection. The generated concept is a toasted sourdough turkey sandwich with tomato, butter lettuce, bacon, cheddar, and aioli. This is a **sandwich**, not a hamburger.

| File | Purpose |
| --- | --- |
| `sandwich-reference.png` | One generated image showing the same sandwich from four angles. |
| `sandwich-study.blend` | Editable Blender scene made through MCP; the reference image is packed into it. |
| `sandwich-hero.png` | Main 3D render. |
| `sandwich-front.png`, `sandwich-side.png`, `sandwich-top.png` | Additional views used for visual checking. |

The Blender result is a stylized first pass rather than a photoreal reconstruction of the reference. The original scene-building source is [`../../sandwich_scene.py`](../../sandwich_scene.py); the workflow and lessons are in [`../../BLENDER_MCP_PLAYBOOK.md`](../../BLENDER_MCP_PLAYBOOK.md).
